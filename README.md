# Training Planner

## Автор
**Боженко Эдуард**

## Описание
Training Planner - это desktop-приложение для планирования и учёта спортивных тренировок. Приложение позволяет добавлять тренировки с указанием даты, типа и длительности, фильтровать их по различным критериям и сохранять данные в формате JSON.

## Функциональные возможности
- Добавление тренировок (дата, тип, длительность)
- Фильтрация по типу тренировки и дате
- Удаление тренировок
- Сохранение и загрузка данных в/из JSON
- Валидация ввода данных
- Удобный графический интерфейс на tkinter

## Требования
- Python 3.6+
- Стандартные библиотеки (tkinter, json, datetime, os)
